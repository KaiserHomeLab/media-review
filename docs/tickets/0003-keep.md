# 0003: Keep from Media Ops

**Blocked by:** 0001

**Status:** Done. Media Ops Keep button in a Media Ops PR.

## What to build

- API: Keep a queued Title.
- Media Ops: a Keep button on the Review Queue card. This is a Media Ops PR.
- Keep takes the Title out of the Review Queue and clears all its Downvotes, so it starts again from zero. Record the decision in the Title's history.

## Acceptance criteria

- [x] After Keep, the Title is gone from the queue and has no Downvotes.
- [x] Voters can Downvote it again, and it can queue again.
- [x] Keep on a Title that isn't queued is rejected.
- [x] Keep appears in the Title's history on later Review Queue entries.
