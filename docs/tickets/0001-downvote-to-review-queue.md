# 0001: Downvote a Title until it shows on a Media Ops Review Queue card

**Blocked by:** none. This is the tracer bullet.

## What to build

The smallest end-to-end path. A Voter signs in with Plex and Downvotes a Title. Once the threshold is met, the Title shows on a Review Queue card in Media Ops.

- **Sign in with Plex** on the web app. Only accounts the server is shared with, and the Owner, get in. The Owner is the server's owner account.
- **Titles** from the Plex libraries: whole movies and whole shows.
- **Play history sync from Tautulli**, giving each Voter's Watches and Samples per Title and their watching over the Base Weight window.
- **Rules as pure functions**, with unit tests: Sample, Audience, Base Weight, Title Bonus, Vote Weight, and the threshold check (Minimum Audience and Downvote share). Use the spec's defaults as constants for now. Ticket 0011 makes them editable.
- **Cast a Downvote** from a Title page. One per Voter per Title. Voters see only their own Downvotes.
- **Re-run the threshold check** on every Downvote and after every Tautulli sync. A Title that passes is added to the Review Queue.
- **API**: API-key auth (key generated by the Owner in Media Review) and `GET` Review Queue. Each entry carries the fields listed in the spec under "API for Media Ops", including each Downvote's Voter and Vote Weight.
- **Media Ops** (separate PR in KaiserHomeLab/media-ops): Media Review under Settings → Add app with address and API key, and a read-only Review Queue card. Optional, and no rules in Media Ops.

## Acceptance criteria

- [ ] A shared Voter can sign in with Plex. An account the server isn't shared with can't.
- [ ] Unit tests cover:
  - a Sample at exactly 30 minutes (movie) and 10 minutes (show), added up across sessions and episodes.
  - a Watch counting as a Sample.
  - a short accidental play counting as neither.
  - Base Weight at 0 and at 1.
  - Title Bonus of +2.
  - a Title below the Minimum Audience never queuing, while its Downvotes are kept.
  - a Title at exactly 50% of the Audience's Vote Weight queuing.
- [ ] A Title below the Minimum Audience queues on a later sync once its Audience reaches 3, using the Downvotes already cast.
- [ ] A second Downvote by the same Voter on the same Title is refused.
- [ ] The Review Queue API rejects requests without a valid API key.
- [ ] With Media Review added in Media Ops, a queued Title appears on the Review Queue card with its Downvotes and weights. Without it, Media Ops behaves as before.
