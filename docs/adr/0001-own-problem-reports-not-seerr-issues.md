# Problem Reports are built into Media Review, not taken from Seerr Issues

Seerr already has a built-in Issues feature that covers most of what a Problem Report needs: per-title reports, an Owner view and a notification back to the reporter. We build Problem Reports into Media Review anyway, so Downvotes, Objections and Problem Reports all live in one system that Voters use from one place (the web app or the Discord bot). Problem Reports stay a separate concept from Downvotes and never count toward removing a Title.

## Considered Options

- **Use Seerr Issues as-is.** No build cost, and Voters already have Seerr logins. Rejected so that everything a Voter does happens in one place.
